Le protocole Raft est un algorithme de consensus distribué conçu pour les systèmes de gestion de base de données. Il utilise une approche leader-follower pour atteindre l'accord, où un leader est élu parmi les nœuds du système. Les avantages du protocole Raft incluent sa simplicité, sa fiabilité et sa capacité à gérer les échecs de nœuds.
